## 鋳造価格 計算ツール（`/yuai2026/`）

ワックス原型の重量から、**シルバー・真鍮**などの金属の鋳造価格を見積もる WEB ツールです。
ジュエリー制作の見積り用。単一 HTML ファイル（`yuai2026/index.html`）で動きます。

### 使い方

1. `tools.kakipo.com/yuai2026/` を開く（ローカルなら `yuai2026/index.html` をブラウザで開く）
2. **ワックス重量(g)** を入力
3. 金属（シルバー / 真鍮）を選択
4. 工賃・地金代・合計（税込）が自動計算されます

単価はすべて**税込**で扱い、合計も税込で表示します（消費税を別途加算しません）。
`⚙ 単価・係数の設定` から各単価を手動調整でき、変更はブラウザに保存されます（`初期値に戻す` で既定値に戻せます）。

#### 地金相場の自動取得

銀地金の価格は、**GitHub Actions が日次で取得**（`scripts/update_prices.rb`・Ruby）し保存します。

- **鋳造相場**: Seaforce（加工net）の[鋳造料金表](https://www.kakounet.com/cast/cast/price.html) SV925/950（税込・円/g）→ シルバー地金単価へ自動反映
- **一般相場**: [田中貴金属](https://gold.tanaka.co.jp/commodity/souba/) 銀 店頭小売価格（税込・円/g）→ チャート用
  ※2026-10-23 以降、先方のアクセス制限（GitHub Actions のIP帯に HTTP 503）により取得停止中。
  1日1回だけ軽く試行し、復活したら自動で記録を再開します（取得できなくてもビルドは失敗扱いにしない）。
- **銀スポット**: [LBMA 銀価格](https://prices.lbma.org.uk/json/silver.json)（USD/オンス）× [Frankfurter API](https://frankfurter.dev/)（ECB公式 USD/JPY）から換算した 円/g（税抜）→ チャート用。
  いずれもプログラム利用前提の公開API。履歴ごと取得し、欠けている日付へ自動バックフィルします。

出力ファイル:
- `yuai2026/prices.json` … 最新スナップショット（ページ起動時に読み、地金単価へ反映）
- `yuai2026/prices-history.json` … 日次の時系列（当日分を upsert。**チャート用**）

取得失敗時は、計算ツール用の最新値（prices.json）は前回値で補完して動作を維持します。
一方、履歴（prices-history.json）には**実際に取得できた値だけ**を記録し、補完値は入れません（取得できなかった日はその系列が欠測になります）。真鍮・工賃は固定値のため対象外です。

#### 価格推移チャート

ページ内に **銀地金の価格推移チャート**（Chart.js）を表示し、「鋳造相場（Seaforce・税込）」「一般相場（田中貴金属・税込）」
「銀スポット（LBMA×ECB換算・税抜）」の3系列を重ねて描画します。鋳造・一般は導入日から日次蓄積、スポットは履歴から自動バックフィルされます。

> 表示価格はあくまで目安です。実際の請求は仕上がり時の地金相場によります。3系列は基準が異なります
> （鋳造＝SV925/950・加工込み税込／一般＝純銀小売税込／スポット＝卸相場の換算・税抜）。

### 計算式

```
金属重量 = ワックス重量 × 比重 × (1 + 湯口率)   ※湯口率は金属重量に加算する目減り割合
合計（税込）= 金属重量 × 工賃単価(円/g) ＋ 金属重量 × 地金単価(円/g)
```

#### 既定値（税込）

| 金属 | 比重 | 工賃 (円/g) | 地金単価 (円/g) |
|------|------|------------|----------------|
| シルバー (SV925/950) | 10.5 | 132 | 476 ※自動更新 |
| 真鍮 | 8.6 | 154 | 33 |

※ 湯口・鋳造追加率 +2%（金属重量に対して） / 地金単価は税込

## 公開のしくみ（GitHub Pages + 独自ドメイン）

- `main` への push で `.github/workflows/deploy-pages.yml` が走り、リポジトリ全体を GitHub Pages にデプロイします。
- ルートの `CNAME` ファイルで独自ドメイン `tools.kakipo.com` を指定しています。
- 新しいツールを追加するときは、リポジトリ直下に `<ツール名>/index.html` を置くだけで `tools.kakipo.com/<ツール名>/` で公開されます。
- `.github/workflows/update-prices.yml` が日次（cron）で `scripts/update_prices.rb`（Ruby）を実行し、地金相場を取得して `yuai2026/prices.json` を更新・再デプロイします（手動実行も可）。

### 独自ドメインの DNS 設定（初回のみ）

DNS プロバイダで以下の CNAME レコードを追加します。

```
tools.kakipo.com.  CNAME  kakipo.github.io.
```

その後、**Settings → Pages → Custom domain** に `tools.kakipo.com` を設定し、証明書が発行されたら **Enforce HTTPS** を有効化します。
